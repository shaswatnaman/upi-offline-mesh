1Compose & Encrypt Payment

The sender's phone generates a random AES-256-GCM key, encrypts the payment, then wraps the AES key with the server's RSA-2048 OAEP public key. Result is a MeshPacket injected into phone-alice.

→
₹ PIN
What just happened: A fresh AES-256-GCM key was generated in RAM. The UPI payload (₹ amount, VPAs, PIN hash) was encrypted with it. The AES key was then RSA-OAEP wrapped — only the server's private key can open it. The sealed MeshPacket (ciphertext + wrapped key + TTL=5) now sits on phone-alice waiting to gossip.
2 Gossip Through the Mesh

Each phone picks a random neighbour and forwards any packets it holds. TTL decrements each hop — like epidemic broadcast. Run multiple rounds to spread the packet closer to the bridge node.

What just happened: Each offline phone checked its neighbour list and forwarded packets the neighbour didn't already hold. TTL decremented per hop. Watch the glowing blue dots move between phone screens — each dot is a copy of your encrypted packet propagating through the mesh.
3 Bridge Uploads to Backend

phone-bridge gets 4G signal and POSTs all held packets to /api/bridge/ingest in parallel. The server decrypts, verifies, deduplicates via hash, and settles the transaction.

What just happened: Bridge nodes uploaded packets using Java's parallelStream(). The server unwrapped the RSA-sealed AES key, decrypted the payload, verified PIN, then checked the packet hash in the idempotency cache. First arrival → SETTLED (balances updated, written to DB via JPA + JDBC). Duplicate arrivals → DUPLICATE_DROPPED.

⚙️ Implementation Reference
Crypto — HybridCryptoService

RSA-2048 OAEP-SHA256 encrypts a per-packet AES-256-GCM session key.
ServerKeyHolder generates the keypair at startup.
Only the server private key can decrypt payment data.

Plain JDBC — LedgerJdbcDao

Uses raw PreparedStatement (not JPA).
Methods: summary(), findBySender(), databaseInfo()
SQL-injection safe via bind parameters (covered by test).

File Handling

LedgerFileService — streams live CSV exports to disk.
AuditLogService — appends every ingest event to a rotating log.
Path traversal blocked in LedgerExportServlet.

Custom Servlets

HealthServlet — DB ping + uptime JSON
LedgerExportServlet — stream / save / list / serve CSV
AuditLogServlet — tail log lines
RequestLogFilter — injects X-Request-Id

Idempotency

IdempotencyService holds a time-bounded ConcurrentHashMap of packet hashes. Bridge nodes upload in parallel — only the first arrival settles, the rest return DUPLICATE_DROPPED.

Gossip Simulator

MeshSimulatorService — 4 VirtualDevice nodes.
BridgeIngestionService — decrypts, verifies, deduplicates, settles.
DemoService — builds signed + encrypted packets.
